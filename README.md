## Main Features
<a id="main-features"></a>

### Core Functionality
- **FluidSynth Integration** — MuseScore includes FluidSynth, a built-in synthesizer that enables users to generate a wide variety of sounds for their compositions.
- **MIDI Keyboard Support** — Users can input notes directly through a MIDI keyboard, facilitating a more intuitive and efficient composition process.
- **MusicXML and MIDI Export** — The software allows for easy export of scores in MusicXML and MIDI formats, making it compatible with various other music production tools.
- **Multi-Voice Support** — MuseScore supports up to four different voices on a single stave, providing composers with greater flexibility in their arrangements.
- **Customizable Interface** — Users can hide toolbars to create a clearer workspace, enhancing focus on the music composition itself.

### Advanced Capabilities
- **Comprehensive Music Symbols Library** — The sidebar tool provides access to an extensive library of music symbols, allowing for detailed and accurate notation.
- **Print and Playback Options** — Composers can print their scores or play them back using integrated playback features, making it easy to review compositions.
- **User-Friendly Interface** — MuseScore's layout is designed for ease of use, ensuring that both beginners and advanced users can navigate the software efficiently.
- **Cross-Platform Compatibility** — Although designed for Windows, MuseScore is available on multiple platforms, allowing for collaborative work among users on different operating systems.
